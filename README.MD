# Energy Consumption Tracker

This PHP-based application allows users to track and view their electricity and water consumption. It includes a login system, database management with MySQL (using phpMyAdmin), and personalized consumption tips based on usage levels. It uses 2 php files a database and js animations for the typewriter.
